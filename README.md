# LunaFlow Levels — AI review mirror

This is a **public, deliberately limited review mirror** of selected files from the private [LunaFlow Levels source repository](https://github.com/ballidan-blip/lunaflow-levels).

## Published files

- `app/weekly.py` — weekly market-analysis and POI-map logic.
- `tests/test_weekly.py` — focused tests for that module and its integration points.
- `.github/workflows/deploy.yml` — a **sanitized, disabled review copy** of the deployment workflow.

## Important boundaries

- The original source repository remains private and is the source of truth.
- This repository contains only selected review files; it is not a standalone runnable application. Dependencies and supporting application modules are intentionally omitted.
- The workflow is disabled in this mirror. The deployment host, account, and remote command have been redacted. Do not treat this copy as a deployable workflow.
- The files were copied from the source repository's `main` branch on 2026-10-28. The private repository remains authoritative and later changes will not automatically appear here.
- Please focus reviews on correctness, edge cases, test quality, security implications, and maintainability. Clearly distinguish confirmed bugs from speculative improvements.
